# Support Model

## Support Tiers

### Community Support (Free)

- GitHub Issues
- Documentation
- Community forums
- Response time: Best effort

### Business Support ($500/month)

- Email support
- 4-hour response time (business hours)
- Priority bug fixes
- Monthly check-in calls

### Enterprise Support ($2000/month)

- 24/7 phone support
- 1-hour response time (critical)
- Dedicated support engineer
- Custom feature development
- On-site training available
