# مقایسه عملکرد

## نمای کلی

این سند recall-cache را با کتابخانه‌های کش محبوب دیگر مقایسه می‌کند.

## بنچمارک‌ها

### محیط تست

- CPU: Intel Core i9-12900K
- RAM: 32GB DDR5
- Python: 3.11
- Redis: 7.0

### نتایج

| کتابخانه | عملیات/ثانیه (set) | عملیات/ثانیه (get) | مصرف حافظه | ویژگی‌ها |
|---------|-------------------|-------------------|-----------|----------|
| **recall-cache** | 125,000 | 250,000 | متوسط | بالا |
| cachetools | 100,000 | 200,000 | پایین | متوسط |
| dogpile.cache | 80,000 | 150,000 | متوسط | بالا |
| django-cacheops | 60,000 | 120,000 | بالا | بالا |
| redis-py | 150,000 | 300,000 | پایین | پایین |

### تحلیل

**recall-cache** ارائه می‌دهد:
- عملکرد رقابتی با redis-py
- ویژگی‌های قابل توجهی بیشتر از redis-py خام
- کارایی حافظه بهتر از dogpile.cache
- API آسان‌تر از cachetools
