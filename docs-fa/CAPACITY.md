# برنامه‌ریزی ظرفیت

## نمای کلی

این سند راهنمایی‌هایی برای برنامه‌ریزی ظرفیت با recall-cache ارائه می‌دهد.

## راهنمایهای مقیاس‌پذیری

### مقیاس‌پذیری عمودی

- افزایش `maxsize` برای MemoryBackend
- افزایش `max_size_bytes` برای DiskBackend
- افزایش `max_connections` برای RedisBackend

### مقیاس‌پذیری افقی

- افزایش سرورهای برنامه
- استفاده از Redis Cluster برای L2
- پیاده‌سازی consistent hashing

## مانیتورینگ

متریک‌های کلیدی برای مانیتورینگ:

- مصرف حافظه
- مصرف دیسک
- تعداد کلیدها
- نرخ hit
- نرخ خطا
- تأخیر (P50, P95, P99)
