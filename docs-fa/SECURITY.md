# حسابرسی امنیتی

## نمای کلی

recall-cache امنیت را جدی می‌گیرد. این سند رویه‌های امنیتی و یافته‌های حسابرسی را تشریح می‌کند.

## اقدامات امنیتی

### رمزنگاری

- **AES-256-GCM** برای رمزنگاری بک‌اند دیسک
- پشتیبانی از **TLS** برای اتصالات Redis
- پشتیبانی از **چرخش کلید** برای کلیدهای رمزنگاری

### احراز هویت

- پنل ادمین از احراز هویت مبتنی بر توکن پشتیبانی می‌کند
- پشتیبانی از احراز هویت رمز عبور Redis
- هیچ اعتبارنامه ثابتی وجود ندارد

### اعتبارسنجی ورودی

- تمام ورودی‌ها قبل از پردازش اعتبارسنجی می‌شوند
- Type hints در کل کدباس اعمال شده
- هیچ ریسک تزریق SQL وجود ندارد (از SQL استفاده نمی‌شود)

## یافته‌های حسابرسی

### 2024-01-15: حسابرسی داخلی

| شدت | یافته | وضعیت |
|-----|--------|--------|
| پایین | بدون محدودیت نرخ در پنل ادمین | در v1.0.0 رفع شد |
| اطلاعات | هدرهای امنیتی گمشده | در v1.0.0 رفع شد |
| اطلاعات | پیکربندی CORS وجود ندارد | مستند شده |

### توصیه‌ها

1. **احراز هویت را فعال کنید** در پنل ادمین در پروداکشن
2. **از TLS استفاده کنید** برای اتصالات Redis
3. **کلیدهای رمزنگاری را بچرخانید** به طور منظم
4. **لاگ‌های دسترسی را مانیتور کنید** برای فعالیت مشکوک
