# مدل پشتیبانی

## سطوح پشتیبانی

### پشتیبانی جامعه (رایگان)

- GitHub Issues
- مستندات
- انجمن‌های جامعه
- زمان پاسخ: بهترین تلاش

### پشتیبانی تجاری ($500/ماه)

- پشتیبانی ایمیلی
- زمان پاسخ ۴ ساعت (ساعات کاری)
- رفع باگ‌های اولویت‌دار
- تماس ماهانه بررسی

### پشتیبانی سازمانی ($2000/ماه)

- پشتیبانی تلفنی ۲۴/۷
- زمان پاسخ ۱ ساعت (حیاتی)
- مهندس پشتیبانی اختصاصی
- توسعه ویژگی سفارشی
- آموزش حضوری در دسترس
